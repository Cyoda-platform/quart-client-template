# Telegram Bot for Currency Exchange

## Описание
Этот бот позволяет пользователям обменивать криптовалюту и фиатные средства.

## Установка
1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Настройте переменные окружения в `.env`

## Запуск
Запустите бота с помощью команды: `python src/application/bot.py`
